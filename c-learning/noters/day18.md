# Day18 - 大模型与AI辅助开发

## 大模型本质

  大模型 = 概率预测模型
  内部有大量参数, 通过统计规律预测下一个词

## 使用方式

  1. 对话式: ChatGPT, Claude, 文心一言等
  2. API调用: 通过 HTTP 请求调用模型接口
  3. Function Calling: 模型调用定义好的函数
  4. MCP协议: 统一协议层, 标准化 AI 工具调用

## AI辅助开发场景

  - 代码生成: 生成模板代码
  - Debug: 帮助分析和修复 bug
  - 代码解释: 理解复杂逻辑
  - 重构: 优化代码结构
  - Prompt Engineering: 编写有效的提示词

## Spec-driving

  文档约束工作流:
  准备一份规范文档, 让 AI 按照文档要求执行
  不需要每次都手动声明限制

## Skill (技能)

  将 prompt 文档化, 操作流程固定化
  便于复用和分享

## Agent

  本质: 在本地循环运行的程序
  具备: 感知 -> 思考 -> 行动 -> 观察 -> 再思考 的能力

## 常见模型平台

  OpenAI (GPT系列)
  Anthropic (Claude)
  百度 (文心一言)
  阿里 (通义千问)
  本地: Ollama (LLaMA, Qwen 等)
