## ➕ 扩展指南

### 新增笔记目录
直接在 `c-learning/` 下创建新目录即可，例如：
```
c-learning/
├── 07_projects/          # 项目实战
│   ├── calculator/
│   ├── todo-list/
│   └── ...
├── 08_references/        # 参考资料
│   ├── cheatsheets/
│   └── ...
```

### 在总表中添加新条目
按上面表格的 Markdown 格式追加行即可。`Day` 列建议保持编号连续或按主题分段。
