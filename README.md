# C语言学习笔记

## 目录

```
├── README.md
├── .gitignore
├── notes/           # 学习笔记 (day01-day23)
├── mindmaps/        # 思维导图 (.mm + .pos)
├── preview/         # 预习资料 (PDF)
└── misc/            # 盲点记录、备忘等
```

## 使用方式

```bash
# 克隆仓库
git clone https://github.com/sorcerer0o/c-learning.git

# 配合代码练习
git clone https://github.com/sorcerer0o/c.git
```

学习流程：看 `notes/dayXX-主题.md` → 对照 `mindmaps/dayXX-主题` → 在 `~/code/c/` 下写代码
