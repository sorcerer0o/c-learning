# Day06 - 函数详解

## 函数三要素

  输入 (参数) -> 处理 (函数体) -> 输出 (返回值)

## 栈帧 (函数调用过程)

  1. 调用函数时, 系统创建栈帧, 压入栈
  2. 栈帧存: 局部变量, 返回地址, 返回值
  3. 函数结束, 弹栈 (移动栈顶指针)
  4. 只有栈顶的局部变量有效

### 栈区

  优点: 简单高效, 自动管理内存
  缺点: 空间小, 编译时确定大小

## 局部变量

  - 生命周期: 函数调用时存在, 结束后销毁
  - 可通过指针拿到地址, 但结束后不要使用 (悬空指针)

## 全局变量

  - 存储在数据段, {} 外定义
  - 未初始化默认为 0
  - 跨文件访问: extern int global_var;
  - 缺点: 多文件可修改, 排查困难

## static 关键字

  修饰全局变量: 作用域缩小到当前文件 (内部链接)
  修饰局部变量:
    - 首次调用初始化, 后续不再初始化
    - 生命周期延长到整个程序运行
    - 作用域仍在函数内

## 值传递 vs 地址传递

  值传递:   传实参的副本, 不影响实参
  地址传递: 传实参的地址, 可通过指针修改

  void swap(int *a, int *b) {  // 地址传递
      int tmp = *a;
      *a = *b;
      *b = tmp;
  }

## 递归

  核心要素:
    1. 递归出口 (终止条件)
    2. 递归过程 (向出口推进)

  优缺点:
    优点: 代码简洁, 逻辑清晰
    缺点: 层级过深栈溢出, 有重复计算

  // 阶乘
  int fact(int n) {
      if (n <= 1) return 1;
      return n * fact(n - 1);
  }

  // 斐波那契
  int fib(int n) {
      if (n <= 1) return n;
      return fib(n-1) + fib(n-2);
  }

## 代码示例

  #include <stdio.h>

  // static 局部变量
  int counter(void) {
      static int count = 0;  // 只初始化一次
      return ++count;
  }

  // 递归: 汉诺塔
  void hanoi(int n, char from, char to, char aux) {
      if (n == 1) {
          printf("Move disk 1 from %c to %c\n", from, to);
          return;
      }
      hanoi(n - 1, from, aux, to);
      printf("Move disk %d from %c to %c\n", n, from, to);
      hanoi(n - 1, aux, to, from);
  }

  int main(void) {
      printf("%d\n", counter());  // 1
      printf("%d\n", counter());  // 2
      printf("%d\n", counter());  // 3
      return 0;
  }

## 常见错误 / 盲点

  1. 返回局部变量地址:
     int* func() { int x = 10; return &x; }  // 危险!
  2. 递归没有出口: 导致栈溢出
  3. 函数传参用数组:
     void func(int arr[])  // arr 退化为指针
     sizeof(arr)  // 是指针大小, 不是数组大小

## 面试常问

  Q: static 关键字的作用?
  A: 1. 修饰局部变量: 延长生命周期, 只初始化一次
     2. 修饰全局变量/函数: 限制在当前文件

  Q: 值传递和地址传递的区别?
  A: 值传递复制一份给形参, 修改不影响实参;
     地址传递传指针, 可通过指针修改实参。
