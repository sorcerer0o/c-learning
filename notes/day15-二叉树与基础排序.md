# Day15 - 二叉树与基础排序

## 二叉树

### 数组模拟二叉树

  左子树: 2*i + 1
  右子树: 2*i + 2
  特点: 必须是满二叉树或完全二叉树

### 二叉搜索树 (BST)

  左子树所有节点 < 根节点 < 右子树所有节点
  中序遍历得到有序序列

  typedef struct treenode {
      int data;
      struct treenode *left;
      struct treenode *right;
  } TreeNode;

## 基础排序算法

### 选择排序

  每轮选最小值, 放到当前位置
  O(n^2), 不稳定

  for (int i = 0; i < n - 1; i++) {
      int min_idx = i;
      for (int j = i + 1; j < n; j++)
          if (arr[j] < arr[min_idx]) min_idx = j;
      swap(&arr[i], &arr[min_idx]);
  }

### 冒泡排序

  每轮从头到尾比较相邻元素, 大则交换
  O(n^2), 稳定

  for (int i = 0; i < n - 1; i++) {
      for (int j = 0; j < n - 1 - i; j++) {
          if (arr[j] > arr[j + 1])
              swap(&arr[j], &arr[j + 1]);
      }
  }

### 插入排序

  将元素插入已排序序列的合适位置
  O(n^2), 稳定
  适用于: 基本有序的小规模数据

  for (int i = 1; i < n; i++) {
      int key = arr[i], j = i - 1;
      while (j >= 0 && arr[j] > key) {
          arr[j + 1] = arr[j];
          j--;
      }
      arr[j + 1] = key;
  }

### 希尔排序

  插入排序的改进, 先分组排序, 最后整体插入
  减少了插入时数据搬移的次数

## 算法复杂度速查

  选择排序: O(n^2)   不稳定
  冒泡排序: O(n^2)   稳定
  插入排序: O(n^2)   稳定
  希尔排序: O(n^1.3) 不稳定

## 面试常问

  Q: 说说插入排序的思路?
  A: 将数组分为已排序和未排序两部分,
     每次从未排序取一个, 插入到已排序的正确位置。

  Q: 排序算法稳定性的含义?
  A: 相等元素排序后相对顺序不变。冒泡/插入稳定, 选择/希尔不稳定。
