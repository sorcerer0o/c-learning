# Day07 - 指针基础

## 内存地址

  - 内存地址: 虚拟内存空间某一字节的唯一标识符
  - 变量地址: 变量所占内存空间首字节地址

  32位: 指针 4 字节, 地址空间 4GB
  64位: 指针 8 字节, 地址空间 16EB

## 指针 vs 指针变量

  指针 = 地址
  指针变量 = 存储地址的变量

  int num = 10;
  int *p = &num;      // 指针变量 p 存 num 的地址
  *p = 20;             // 解引用, 修改 num 的值为 20

## 指针的声明与初始化

  int *p;              // 声明 (未初始化, 野指针)
  int *p = &num;       // 初始化为变量地址
  int *p = NULL;       // 初始化为空指针
  int *p = other_p;    // 初始化为另一指针

## 解引用

  *p = 20;             // 写: 通过 p 修改指向的内存
  int val = *p;        // 读: 通过 p 读取指向的值

  直接访问: 读内存一次
  解引用: 读内存两次 (先读指针值, 再读目标)

## 空指针 NULL

  NULL 指向一块明确不可用的位置 (地址 0)
  使用空指针导致程序崩溃
  使用前应判空: if (p != NULL) { *p = 10; }

## 野指针 (悬空指针)

  出现情况:
    1. 未初始化
    2. 用无效整数赋值
    3. 指向已释放的内存 (free 后未置 NULL)

  原则: 不知道指向哪里时, 先指向 NULL

## void* 通用指针

  void *p = malloc(100);   // 只存地址, 不存类型
  // 不能解引用, 不能算术运算
  int *arr = (int *)p;     // 使用时需转换

## 二级指针

  int num = 10;
  int *p = &num;           // 一级指针 (存 int 的地址)
  int **pp = &p;           // 二级指针 (存指针的地址)

  **pp = 20;               // 修改 num 为 20
  *pp = &other;            // 修改 p 指向 other

## 指针与数组

  int arr[5];
  arr        // 首元素地址 (int*)
  &arr[0]    // 同上
  &arr       // 整个数组的地址 (int (*)[5])

  arr 在两种情况下不是首地址:
    1. sizeof(arr)  → 整个数组大小
    2. &arr         → 数组指针

## 指针运算

  p + n       // 地址加 n * sizeof(类型)
  p - n       // 地址减 n * sizeof(类型)
  p1 - p2     // 两地址相差的元素个数

  int arr[5] = {1,2,3,4,5};
  int *p = arr;
  printf("%d\n", *(p + 2));  // 3
  printf("%lld\n", (long long)(&arr[4] - &arr[0]));  // 4

## 代码示例

  #include <stdio.h>

  int main(void) {
      int a = 10, b = 20;
      int *p1 = &a, *p2 = &b;

      // 指针赋值与解引用
      printf("a = %d, *p1 = %d\n", a, *p1);
      *p1 = 30;  // 通过指针改 a
      printf("a = %d\n", a);

      // 指针比较: 比较地址高低
      printf("p1 > p2? %d\n", p1 > p2);  // 取决于栈地址

      // 指针 + n
      int arr[3] = {1,2,3};
      int *pa = arr;
      printf("%d %d %d\n", *pa, *(pa+1), *(pa+2));

      return 0;
  }

## 常见错误 / 盲点

  1. 解引用未初始化的指针:
     int *p; *p = 10;  // 崩溃! p 指向随机地址
  2. 返回局部变量地址:
     int* func() { int x = 10; return &x; }  // 悬空指针
  3. free 后未置 NULL:
     free(p); p = NULL;  // 避免悬空

## 面试常问

  Q: 说说对指针的理解?
  A: 指针就是地址。指针变量存储地址。
     通过指针可以间接访问和修改内存。
     使用前要判空, 避免野指针。

  Q: NULL 是什么?
  A: 空指针常量, 值为0。
     表示指针不指向任何有效内存。
     使用前应判空。
