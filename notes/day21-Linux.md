## Linux文件系统：
- 虚拟文件系统：就是一套虚拟的文件系统，使用这个文件系统，可以映射到不同的盘上；
- 虚拟文件系统到物理文件系统之间存在映射；
- ln 创建硬链接命令，ln file1 file2 将file2 连接到file1的inode 上修改其中的一处文件内容，另一个有会被修改；当inode的链接数为"0"才会释放；
- 目录的硬连接数比较特殊，因为创建就存在"."和".."，".."对应上一级目录,所以没创建一个目录，其上一级的目录链接数+1;
- 权限掩码：umask // 实际权限 = 默认权限(一般新建的普通文件的权限是664；一般新建的目录或可执行程序的初始权限就是775) & ~mask;
- rmdir:可用于清除空文件夹；
- 通配符：1. * 表示匹配 0 个和任意多个；
          2. ？表示匹配任意1个字符；
          3.[...] 表示匹配括号中的任意字符；
- VIM 小技巧：
    C-v: 竖选模式；
    df:
    t/T:
    f/F:
    p/P:
    在""中使用di:将光标所在的""中的内容删除并进入插入模式；
    在()中使用di:将光标所在的()中的内容删除并进入插入模式；
    [n]dd：向下删除n行；
    diw：将光标所在单词删除；
    [n][m]yy: 复制[n,m]行；
    替换文本指令：
      - %s ../../g
      - %s ../../gc
      - s ../../
      - s ../../g
    gg=G:格式化；
    怎么格式化选中的；
- gcc 的 预处理指令：
    -E : 转化为.i文件(预处理)
    -S : 转化为.s文件(编译);
    -c : 转化为.c文件(汇编);
    -o : 转化为可执行文件；
- xdd:
- gcc处理时不需要加入.h头文件但是会有warning;
- 分屏显示文件内容-- more;
- which:显示命令所在路径；
- "locate"命令通过搜索预构建的数据库来快速查找文件，支持统配符，速度比"find"快，但是数据库需要定期更新（通常每天自动更新或手动执行"updaetdb";
- rmdir dir*会删除dir/
- 文件权限：ll显示三种权限，第一为文件创建者的权限，第二为同组成员的权限，第三为其他权限；三者的"wrx"的权限位置固定，没有就用"-"替代；
- chmod的权限数字代表3组二进制数，每组转化为八进制数，列如 “wrxwrxwrx" 二进制表述为"111 111 111" 转化为八进制数就是 "777"
- echo :sudo 也不能通过echo > 传权限，因为">"重定向，sudu不能赋权到">"之后；
- 如歌没有读权限r,使用vim强行打开文件不会显示文件内容，修改文件内容后新内容会把旧内容覆盖，旧内容会在~file临时存放；
- 目录流："X"是目录的基础权限，缺失会导致其他操作也出现问题；
