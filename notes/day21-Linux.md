# Day21 - Linux 系统基础

## 文件系统

### 虚拟文件系统 (VFS)
- VFS 是 Linux 内核的抽象层，提供统一的文件操作接口
- 用户通过 VFS 访问不同物理文件系统 (ext4, NTFS, FAT32 等)
- VFS → 映射 → 具体文件系统 → 磁盘设备

### inode
- inode (索引节点) 存储文件的元数据（权限、大小、时间、数据块指针等）
- 文件名存在目录项中，文件名 → 目录项 → inode → 数据块
- `ls -i` 查看文件的 inode 编号
- `stat 文件` 查看 inode 详细信息

### 硬链接
```bash
ln file1 file2    # 创建硬链接，file2 指向 file1 的同一 inode
```
- 硬链接共享同一 inode，修改任一文件内容，另一文件同步变化
- 删除文件只是减少 inode 的链接计数，计数为 0 时才释放数据块
- 不能跨文件系统创建硬链接
- 不能对目录创建硬链接（除 `.` 和 `..`）

### 目录的链接数
- 新创建的目录默认有 `.`（自己）和 `..`（父目录）
- 每创建一个子目录，父目录的链接数 +1
- `ls -ld 目录` 查看目录的链接数

## 文件权限

### 权限分类
```
-rwxr-xr-x
| ||||||||
| |||||||+-- 其他用户权限 (others)
| ||||||+--- 其他用户权限
| |||||+---- 同组用户权限 (group)
| ||||+----- 同组用户权限
| |||+------ 文件所有者权限 (owner)
| ||+------- 文件所有者权限
| |+-------- 文件所有者权限
| +--------- 文件类型 (- 普通, d 目录, l 符号链接)
```

### 权限数字表示
```
rwx = 111 = 7
rw- = 110 = 6
r-x = 101 = 5
r-- = 100 = 4
--- = 000 = 0
```
- `chmod 755 file` 等价于 `chmod u=rwx,g=rx,o=rx file`
- `chmod u+x file` 给所有者添加执行权限

### umask 权限掩码
```bash
umask          # 查看当前掩码
umask 022      # 设置掩码
```
- 实际权限 = 默认权限 & ~umask
- 文件默认 666 (rw-rw-rw-)，目录默认 777 (rwxrwxrwx)
- umask 022 → 文件: 666 & ~022 = 644 (rw-r--r--)
- umask 022 → 目录: 777 & ~022 = 755 (rwxr-xr-x)

### 目录的 x 权限
- 目录的 `r`：可以列出目录内容（ls）
- 目录的 `w`：可以在目录中创建/删除文件
- 目录的 `x`：可以进入目录（cd），**x 是目录的基础权限**
- 目录没有 x 权限，即使有 r 也无法访问文件内容

### sudo 与重定向
```bash
# sudo 不能给 > 重定向符提权
sudo echo "test" > /root/file    # 失败，> 由当前 shell 执行
# 正确做法：
echo "test" | sudo tee /root/file
sudo sh -c 'echo "test" > /root/file'
```

## Vim 进阶技巧

### 竖选模式
- `Ctrl-v` 进入可视块模式，竖选多行后批量编辑

### 文本对象操作
| 命令 | 作用 |
|------|------|
| `di"` | 删除双引号内的内容（光标在引号内） |
| `di(` | 删除括号内的内容 |
| `diw` | 删除光标所在的单词 |
| `daw` | 删除光标所在的单词（包括尾部空格） |
| `ci"` | 修改双引号内的内容 |
| `ca(` | 修改包括括号在内的内容 |

### 移动与复制
| 命令 | 作用 |
|------|------|
| `fX` | 向右查找字符 X 并跳到该位置 |
| `FX` | 向左查找字符 X 并跳到该位置 |
| `tX` | 向右查找 X，跳到 X 前一个字符 |
| `TX` | 向左查找 X，跳到 X 后一个字符 |
| `dfX` | 删除从光标到 X（含 X） |
| `dtX` | 删除从光标到 X（不含 X） |
| `[n]dd` | 向下删除 n 行 |
| `[n][m]yy` | 复制第 n 到 m 行 |
| `p` | 在当前行后粘贴 |
| `P` | 在当前行前粘贴 |

### 替换
```vim
:%s/old/new/g      " 全文替换
:%s/old/new/gc     " 全文替换，逐个确认
:s/old/new/        " 当前行第一个
:s/old/new/g       " 当前行全部
```

### 格式化
- `gg=G` 自动缩进整个文件
- 选中文本后按 `=` 格式化选中区域

## GCC 编译步骤

| 选项 | 输出 | 阶段 |
|------|------|------|
| `-E` | `.i` 文件 | 预处理 (展开宏、头文件) |
| `-S` | `.s` 文件 | 编译 (生成汇编) |
| `-c` | `.o` 文件 | 汇编 (生成机器码) |
| (无) | 可执行文件 | 链接 |

```bash
gcc -E main.c -o main.i   # 预处理
gcc -S main.i -o main.s   # 编译
gcc -c main.s -o main.o   # 汇编
gcc main.o -o main        # 链接
# 一步到位
gcc main.c -o main
```

- 编译时不需要手动引入 .h 文件（预处理会自动展开 #include）
- 但不引入 .h 编译会有 warning（隐式声明）

## 通配符

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `*` | 匹配 0 个或多个任意字符 | `*.c` 所有 .c 文件 |
| `?` | 匹配任意 1 个字符 | `file.?` file.c file.h |
| `[...]` | 匹配括号内任意字符 | `[abc]*` a/b/c 开头的文件 |
| `[!...]` | 匹配不在括号内的字符 | `[!a]*` 非 a 开头的文件 |

## 查找命令

| 命令 | 特点 | 用法 |
|------|------|------|
| `which` | 查找可执行文件路径 | `which gcc` |
| `locate` | 基于数据库快速查找，支持通配符 | `locate "*.c"` |
| `find` | 实时搜索，功能强大 | `find . -name "*.c" -type f` |
| `whereis` | 查找二进制/源码/手册页 | `whereis ls` |

- locate 依赖预构建数据库，每天自动更新，可手动执行 `updatedb`
- find 实时扫描目录，速度较慢但结果最新

## 其他常用命令

- `rmdir` 删除空目录（非空用 `rm -r`）
- `more` 分屏查看文件内容（按空格翻页）
- `xxd` 查看文件的十六进制表示
- `stat` 查看文件详细信息（大小、权限、时间、inode）
